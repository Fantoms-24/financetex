# Скилл: Lead Mobile UI Architect («Листок»)

Данный скилл формулирует архитектурные правила компоновки мобильного интерфейса «Листок».

## 1. Анатомия мобильного экрана (Viewport Hierarchy)

Каждый экран проектируется как нативное мобильное окно с фиксированной шириной (макс. 440px на десктопе, 100% на смартфонах):

1. **Безопасная зона статус-бара (Top Safe Area)**:
   - Высота: `max(env(safe-area-inset-top), 18px)` + отступ заголовка `8px–12px`.
   - Защита от системных элементов (время `06:58`, батарея, Dynamic Island / вырез камеры).
   - При скролле: полупрозрачная шапка с размытием (`backdrop-blur-xl bg-paper/90 border-b border-rule/60`), закрывающая контент от наложения на статус-бар.

2. **Основное полотно контента (Content Canvas)**:
   - Структура: **Inset Grouped Layout** (стандарт iOS / iPadOS / Revolut).
   - Контент не должен представлять собой разрозненные плавающие островки на пестром фоне. Вместо этого он объединяется в логические карточные группы (`rounded-[20px] border border-rule/70 bg-paper shadow-paper`).
   - Горизонтальные поля: строго `px-4 sm:px-5` (16–20px).
   - Вертикальный ритм между карточными группами: `gap-3.5` или `space-y-3.5` (14px).

3. **Нижняя навигационная панель и зона Home Indicator (Bottom Safe Area)**:
   - Панель привязана строго к нижней кромке устройства (`fixed bottom-0 left-0 right-0 z-40`).
   - Фоновая подложка проходит сквозь нижнюю безопасную зону (`pb-[max(env(safe-area-inset-bottom),10px)]`), создавая сплошной премиальный стеклянный барьер без щелей.
   - Любой прокручиваемый экран обязан иметь `pb-32`–`pb-36`, чтобы последний элемент контента можно было прокрутить выше панели и нажать одной рукой.

## 2. Зоны досягаемости большого пальца (Thumb-Zone Ergonomics)

- Главные действия (сканирование, оплата счета, выбор кассы) размещаются в нижней половине экрана (Natural Thumb Zone).
- Минимальный размер кликабельной области (Touch Target): `44×44pt`.
- Второстепенные фильтры и настройки профиля — в верхней трети.

## 3. Правило адаптивности (360px – 430px)

- Никаких жестких фиксированных ширин текстовых контейнеров, способных сломать верстку на узких Android (360px) или старых iPhone (SE 375px).
- Заголовки используют адаптивные размеры: `text-[22px] sm:text-[25px]`.
- При нехватке ширины для многоэлементных блоков (например, 5 табов) обязательно использование `overflow-x-auto no-scrollbar` с эластичной прокруткой.
