# 2026-09-06

## Стабилизация сборки под Vercel

- Раскопал, почему сборка перестала давать `.vercel/output`: в **nitro 3** плагин
  принимает `{ config: NitroConfig }`. Раньше передавали `preset`/`output` напрямую —
  они молча игнорировались, и сборка уезжала в `.output` с пресетом `node-server`.
  Переписал `vite.config.ts` на `nitro({ config: { ... } })`.
- Добавил escape-клапан `NITRO_OUTPUT_DIR` (на деплое переменной нет, путь штатный).
- Пытался вынести PGlite из бандла через `rollupConfig.externals.external` — **не сработало**
  (хэши чанков не изменились). Конфиг удалил, чтобы не оставлять мёртвый код.
  Вместо этого в `src/server/db/index.ts` обернул инициализацию PGlite в понятную
  ошибку «задайте DATABASE_URL» вместо ENOENT.

- `npx tsc --noEmit` — чисто.
- Клиентский бандл чистый: PGlite / pg / better-auth / web-push / node:crypto не утекли.

- `scripts/verify-tick.mjs` (новый): 12 проверок крона через Vite SSR, все зелёные.
  Подтвердил критерий ТЗ: при `sent = 0` (нет подписок или доставка упала)

  каждый уходит по одному разу.
